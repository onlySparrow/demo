# 测试用例：菜单相关功能及展示

> 依据：`doc/统一待办-PC端0727(1).html` 原型（侧边栏 + 共享顶部栏章节）
> 实现对象：`src/layouts/BasicLayout/*`（BasicLayout / AppSidebar / AppHeader / HeaderSlot / menuConfig）、`src/store/menuBadgeStore.ts`、`src/api/menu.ts`、`src/router.tsx`
> 用例基线：当前实现（已按原型落地，个别交互按实现约定执行，差异处在用例中注明）

## 一、通用约定

| 项 | 内容 |
| --- | --- |
| 环境 | `pnpm dev` 启动 PC 端（vite 默认端口），浏览器访问应用 |
| 通用前置 | 已进入系统（当前无登录页，直接进入 `/todo`）；视口 ≥ 1366×768 |
| 角标接口 | `GET /menu/badge-counts`，返回 `{ "<菜单路由>": 数量 }`；联调前不可用，验证接口相关用例时用 DevTools 网络拦截 / vite mock 注入返回值 |
| 优先级 | P0 核心流程（失败即阻断）；P1 重要；P2 次要与细节 |

关键设计值（与 `src/assets/styles/_tokens.scss` 同源，断言时使用）：

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| 主色 `#005daa` | primary | 标题、选中文字、hover 文字 |
| 选中底 `#d4e3ff` | primary-fixed | 菜单选中态背景、批量条底色 |
| 辅助色 `#214ae2` | secondary | 选中项左侧竖条 |
| 错误色 `#ba1a1a` | error | 角标红底 |
| 次文字 `#404753` | text-secondary | 菜单默认文字 |
| hover 底 `#e6e8eb` | surface-container-high | 菜单项 hover 背景 |
| 弱描边 `#c0c7d6` | outline-variant | 分割线、面板描边 |
| 尺寸 | 64px（收起）/ 208px（展开）/ 顶栏 64px | |
